# 회고

이 문서는 Codex 작업 기록이며 팀원의 실제 회고를 대신하지 않는다. 팀은 발표 전에 각자 검토하고 보완해야 한다.

1. 도움이 된 점: 계약서와 테스트를 대조해 상태 전이, 재고 원자성, 결제 실패 처리를 구현했다.
2. 잘못된 방향: 조회의 대표명 재현 테스트가 페이지 결함 때문에 먼저 실패했다. 페이지를 고친 후에도 실패함을 확인하여 해당 결함의 독립 재현을 확인했다.
3. 효과적인 습관: 수정 전 실패하는 테스트와 미션별 테스트 실행이 결함과 회귀를 확인하는 데 유용했다.
4. 규칙: 원본 테스트와 공통 도구를 보존하고 사람의 검토 여부를 사실대로 기록했다.
5. 다음 개선: 사람이 각 미션의 계획과 diff를 직접 검토하고 역할을 교대하며 기록한다.
6. 모호한 점: 수량 변경의 maxAddable은 공개 테스트대로 대체 수량의 상한으로 해석했다. 결제와 취소 또는 만료가 서로 겹치는 상황은 계약에서 명시하지 않았다.

발표 준비: 팀이 실제 검토 결과를 바탕으로 에이전트를 통제한 사례와 오류를 발견한 사례를 선정해야 한다.
