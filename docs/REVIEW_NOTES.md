## 리뷰 체크리스트 (확인한 항목에 표시)

- [ ] 보안 · 권한: 본인의 데이터만 볼 수 있는가?
- [ ] 데이터 정확성: 어떤 값을 어디서 가져오는가? (주문 시점 값 vs 현재 값)
- [ ] 경계 · 오류: 0건, 마지막 페이지, 범위를 벗어난 페이지, 삭제된 상품은?

- [ ] 표시 규칙(대표 상품 등)이 계약과 같은가?
