# Mission 5 코드 리뷰

계약서 5장 기준으로 조회 코드를 검토했다.

| 결함 | 위치 | 위반 | 재현 테스트 | 수정 |
|---|---|---|---|---|
| 타인의 주문 상세 노출 | getOrderDetail | 본인만 조회 | 상세 권한 | 소유권 검사 |
| 현재 상품 가격 사용 | getOrderDetail | 주문 시점 가격 | 주문 가격 스냅샷 | 주문 항목 가격 사용 |
| 오래된 주문 우선, 동시간 tie 미처리 | listOrders | 최신순, 동시간 번호 내림차순 | 최신순 | 두 기준으로 정렬 |
| 첫 페이지 계산 오류 | listOrders | 페이지는 1부터 | 첫 페이지 | (page - 1) 적용 |
| 대표명 나머지 수 오류 | representativeName | 첫 상품 외 나머지 종류 | 대표 상품 | 전체 종류에서 1 차감 |
