## 사용자 스토리와 수락 기준(발췌)

### US-05 장바구니 담기
- 정상: 재고가 10개인 상품을 2개 담으면 장바구니에 수량 2로 표시된다.
- 정상: 이미 2개 담긴 상품을 3개 더 담으면 수량이 5로 합산된다.
- 경계: 재고가 10개인 상품을 11개 담으려 하면 거부되고 담을 수 있는 최대 수량이 안내된다.

### US-06 장바구니 수정
- 정상: 수량을 변경하면 해당 상품의 소계와 장바구니 총액이 즉시 갱신된다.
- 정상: 상품을 삭제하면 목록에서 사라지고 총액이 갱신된다.
- 경계: 수량에 0 또는 음수를 입력하면 거부되며, 삭제는 삭제 버튼을 사용하도록 안내된다.

### US-07 주문 생성
- 정상: 재고가 충분한 상품 2종이 담긴 상태에서 배송지를 입력하고 주문하면 주문이 '결제대기' 상태로 생성되고 주문번호가 발급되며 재고가 주문 수량만큼 차감된다.
- 예외: 재고가 부족한 상품이 포함되어 있으면 주문이 생성되지 않고, 부족한 상품명과 주문 가능한 수량이 안내되며, 재고는 변하지 않는다.
- 예외: 배송지를 입력하지 않으면 필수 입력 안내가 표시되고 주문은 생성되지 않는다.
- 경계: 재고가 1개 남은 상품을 두 구매자가 동시에 주문하면 한 명만 성공하고 다른 한 명은 재고 부족 안내를 받는다. 재고는 0 미만이 되지 않는다.

### US-08 결제
- 정상: 결제에 성공하면 주문이 '결제완료'로 바뀌고 결제 내역이 기록된다.
- 예외: 결제가 실패(예: 한도 초과)하면 실패 사유가 안내되고 주문은 '결제대기'로 유지되며 다시 결제할 수 있다.
- 경계: 결제 버튼을 연속으로 두 번 눌러도 결제는 한 번만 처리된다.
- 보안: 카드번호 등 결제 수단 정보는 시스템의 데이터베이스와 로그 어디에도 저장되지 않는다.

### US-09 주문 내역 조회
- 정상: 본인의 주문이 최신순으로 표시되고, 상세 화면에서 상품, 금액, 배송지, 상태를 확인할 수 있다.
- 예외: 주문이 하나도 없으면 '주문 내역이 없습니다'가 표시된다.
- 보안: 다른 구매자의 주문번호로 접근하면 조회가 거부된다.

### US-10 주문 취소와 환불
- 정상: '결제완료' 상태의 주문을 취소하면 주문이 '취소'로 바뀌고, PG에 환불이 요청되며, 차감되었던 재고가 복원된다.
- 정상: '결제대기' 상태의 주문을 취소하면 환불 요청 없이 주문이 '취소'로 바뀌고 재고가 복원된다.
- 예외: '배송중' 상태의 주문을 취소하려 하면 취소가 거부되고 취소할 수 없는 이유가 안내된다.
- 예외: PG 환불 요청이 실패하면 오류가 기록되어 관리자가 확인할 수 있고, 구매자에게는 처리가 지연된다는 안내가 표시된다.

> 이번 실습은 SRS 의 열린 이슈 OI-01(재고 차감 시점)을 '주문 생성 시 차감'(기준선), OI-03(PG 연동)을 '모의(Mock) PG'로 정한 상태에서 진행한다.
